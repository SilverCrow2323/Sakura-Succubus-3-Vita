# Game files and paths

The VPK installs the Vita application. The original PC game's `game/` directory supplies the visual novel content.

## Expected destination

```
ux0:/app/RNPYSSIII/game/
```

- Keep the title-ID directory exactly as shown.
- Put `game/` inside that directory, not beside it.
- Do not rename or flatten the content directory.

## Original game

Use the official [Steam listing](https://store.steampowered.com/app/1406020/Sakura_Succubus_3/) to obtain the original game.

> [!IMPORTANT]
> **MUST KNOW!!** Do not commit the original game's proprietary files to this repository or attach them to public issues. Share technical logs and paths instead.
