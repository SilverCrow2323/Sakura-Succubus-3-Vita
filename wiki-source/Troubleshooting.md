# Troubleshooting

Check the VPK installation and original game folder before reinstalling.

## Common problems

| Symptom | First check |
|---|---|
| App is not in LiveArea | Confirm the VPK or extracted folder installation completed |
| App opens but content is missing | Check for `ux0:/app/RNPYSSIII/game/` |
| Folder is copied beside the title directory | Move `game/` inside the title-ID folder |
| Install folder option was not used | Repeat VitaShell → TRIANGLE → More → Install folder |
| A menu behaves incorrectly | Record the menu and action; see known issues if listed |

## Known issue

The repository README notes that the **Settings** and **Load/Save** menus can sometimes be glitchy. The **Quick Load/Save** option is reported to work without issues.

- Prefer Quick Load/Save when the full menu behaves incorrectly.
- Record the exact menu, save slot and reproduction steps when reporting a problem.

## Report a problem

Include the Vita model and firmware if known, port version, exact content path, steps to reproduce and complete error text. Do not attach copyrighted game data.
