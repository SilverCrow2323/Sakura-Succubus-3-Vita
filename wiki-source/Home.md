# Sakura Succubus 3 Vita — Vita guide

This Wiki provides the practical install and support notes for Sakura Succubus 3 Vita. The Vita port and the original PC game's content files are separate.

> [!IMPORTANT]
> **MUST KNOW!!** Obtain the original game from its official source. Do not expect the Vita port repository to contain the original proprietary game data.
